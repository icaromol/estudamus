## Banner/cover (opcional)

Se for gerar uma imagem de capa (para o social preview do GitHub e/ou o card do portfólio), o GitHub recomenda **1280×640px** (proporção 2:1), mínimo 640×320px, PNG ou JPG, até 1MB. Gerar em 2x (2560×1280) e reduzir na exportação evita perda de nitidez. O mesmo arquivo pode ser reaproveitado como `cover` do projeto no portfólio (`portfolio/public/images/`), já que a proporção é a mesma.
